A LLM app designed for mobile use. Instead of models running via api providers, the models run completely on your device, including TTS and STT.

This means you could run LLMs completely offline if you lose internet access or simply want privacy.

If a LLM is too slow or wont fit in your ram, try switching to a smaller one.

Some models were specifically fine tuned for this app:

DeepSmolLM3-3B - SmolLM3-3B fine tuned on Deepseek v4.1 outputs and reasoning.

More soon, it takes time to fine tune models.
