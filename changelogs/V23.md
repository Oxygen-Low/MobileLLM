# V23

## Added

- Image generation. Ask the assistant for a picture and it draws one on the device. The chat model is unloaded first so the image model fits in memory, and the chat model comes back as soon as the picture is done.
- The Model Hub has an Image tab. It lists the image models you can download and lets you pick the one pictures are drawn with; the choice is remembered across launches.
- A generated picture can be referenced from the HTML sandbox, so an app or game the assistant builds can show it, and it can be placed in the reply itself.
- Deleting a chat deletes the pictures that were generated in it, and "Clear All" removes every picture.

## Changed

- The Image tab of the Model Hub is no longer a placeholder.
