# V30

## Fixed

- Image and video generation no longer paint with a fresh set of random colours on every request. The palette now comes from the description itself: words such as "red" or "blue" set the colours, and descriptions without a colour word get a stable, repeatable scheme instead of an arbitrary one.
- Repeating the same image or video prompt now produces the same picture instead of a different one each time. You can still pass an explicit seed when you want a variation.
