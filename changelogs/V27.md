# V27

## Fixed

- The interactive HTML sandbox shows the app or game instead of a blank page with a fragment of text on it. An edit that contained unescaped quotes used to be cut short at the first of them, so only the beginning of the page reached the sandbox.
- A page that the assistant wrapped in a markdown code fence, or whose tags were escaped, is cleaned up before the sandbox shows it. Sandboxes saved by earlier versions are repaired the next time they are opened.
- The live preview in a reply and the fullscreen sandbox reload when the page changes, so an app that grew while the reply was still being written no longer stays on screen as an almost empty page.
