# V21

## Added

- Downloads can be cancelled from the model hub. The partial file is kept, so starting the download again resumes where it stopped.

## Changed

- The app now reopens with the model you used last instead of always loading Qwen3. If that model was deleted, another downloaded model is loaded instead.
- The TTS tab shows every voice right away. The extra tap to unfold the voice list is gone.
- LFM2.5-1.2B-Thinking now runs the Q6_K quantisation, which keeps more of the model's quality than the previous Q4_K_M file. It needs a fresh download and about 230 MB more storage.
