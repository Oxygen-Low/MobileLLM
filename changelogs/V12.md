# V12

- Added on-device speech to text and text to speech. Both use small Whisper Tiny and Piper models that are downloaded from the Model Hub on demand and only loaded while their toggle is on.
- Dictation appends the transcribed text to whatever you already typed.
- Added a changelog system. After an update the app asks if you want to read what changed and shows the notes of every version between the one you were using and the one you are on now.
- The release notes of a GitHub release are now taken from the changelog of that version, so the release page and the app always show the same thing.
- The app and its release notes no longer refer to other chat assistants by name.
