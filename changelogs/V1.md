# V1

- First public build. Chats with LLMs that run completely on the device through llama.cpp.
- Works with GGUF and SafeTensors models, including the fine tuned DeepSmolLM3-3B.
- Model Hub to browse, download, reinstall and delete models.
- Streaming answers with selectable reasoning levels and a collapsible reasoning view.
- Chat history is stored on the device and can be reopened from the session drawer.
- The app checks GitHub releases for new builds and can install them for you.
