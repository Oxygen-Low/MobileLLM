# V32

## Added

- Added AI Horde as an optional source of text and image models, so the app can generate replies and pictures with large hosted models when the phone cannot run them locally.
- Added an AI Horde tab in the Model Hub with a saved API key, a searchable list of models that are currently online, and a refresh button. Anonymous use works without a key.
- Added automatic continuation when a reply or a Horde generation stops in the middle of a sentence: the app asks the model to continue and joins the two parts into one answer.

## Changed

- Selecting a Horde chat or image model now keeps it across restarts and uses it for tool calls and image generation just like an on-device model.
